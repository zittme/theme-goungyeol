# Goungyeol (고운결)

[Zittme](https://github.com/zittme/zittme) 엔진용 공식 쇼핑몰 테마입니다. 화장품·뷰티 쇼핑몰을 위해 뷰티 편집숍처럼 흰 여백을 넓게 두고 각진 카드에 상품 사진을 크게 실었으며, 로즈 푸시아 포인트와 블러시 아이보리로 색을 잡았습니다. 상품 카드는 브랜드명과 상품명을 나눠 적고 별점 · 리뷰 수 · 랭킹 번호 · 세일 배지를 함께 보여 줍니다. 레이아웃과 커머스 · 게시판 · 회원 · 쪽지 · 알림센터 · 메시지 · 예약 · 짓미페이 · 문의 · 지식질문 스킨이 한 벌로 맞춰져 있습니다.

- 데모: https://shopdemo2.zitt.me
- 스토어: https://zitt.me/store/package/35206
- 사용자 가이드: https://zitt.me/manual/official/goungyeol-theme

## 요구 사항

- Zittme 1.0.0 이상
- [commerce](https://github.com/zittme/commerce) 1.1.0 이상 권장. 커머스 · 예약 · 짓미페이 · 문의 · 지식질문 등 부가 모듈 스킨은 해당 모듈이 설치된 사이트에서만 적용됩니다.

## 설치

Zittme 설치 경로의 `themes/goungyeol` 에 이 저장소의 내용을 놓습니다. **폴더 이름은 `goungyeol`** 입니다.

```bash
cd 설치경로/themes
git clone https://github.com/zittme/theme-goungyeol.git goungyeol
```

압축 파일로 받았다면 `themes/goungyeol/` 에 풀면 됩니다. 이후 관리자 > 테마에서 고운결을 적용하면 레이아웃과 스킨이 한 번에 바뀝니다.

## 라이믹스에서 쓰기

라이믹스에는 테마 기능이 없어 레이아웃과 모듈 스킨을 따로 지정해야 합니다. 릴리즈에 첨부된 `goungyeol-rhymix-<버전>.zip` 이 그 구조로 나눠 담은 배포판입니다. 압축을 풀어 `layouts` 와 `modules` 를 라이믹스 설치 폴더에 올린 뒤 사이트 디자인 설정에서 레이아웃과 스킨을 하나씩 고르면 됩니다.

- 라이믹스 자료실: 레이아웃만 별도로 등록되어 있어 쉬운 설치로 받을 수 있습니다. 스킨까지 쓰려면 릴리즈의 전체 묶음을 받으세요.
- 라이믹스 코어에 없는 기능(목록형 설정 항목, 본인인증, SNS 로그인)은 고정 칸으로 대체되거나 화면에서 숨겨집니다. 자세한 내용은 배포판 안의 README 를 보세요.
- 라이믹스 호환은 베타입니다. 문제가 보이면 https://zitt.me/issue 에 알려 주세요.

## 구성

- 레이아웃 `goungyeol`: 가운데 로고 헤더와 검색창, 비주얼 슬라이더(문구 정렬 선택), 글자형 카테고리 인덱스(아이콘 이미지 지정 가능), 일일특가 · 기획전 · 추천 · 랭킹 · 신상품 · 할인 상품 등 메인 구성 블록, 모바일 하단 탭바, 포인트 색 변경
- 모듈 스킨 `goungyeol`: 커머스 · 게시판 · 회원 · 쪽지 · 알림센터 · 메시지 · 예약 · 짓미페이 · 문의 · 지식질문
- 커머스 스킨: 브랜드명과 상품명 분리, 별점 · 리뷰 수 · 랭킹 번호 · 세일 배지, 안내문 HTML, 배너 포인트 이미지 정렬, 주문 상태 필터
